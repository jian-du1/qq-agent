# 内置扩展市场 0.3.4

QQ Agent 控制台扩展插件：启用后增加「市场」页，可切换插件、技能和人设。展示官网已审核且有效的条目，按更新时间排列。使用间隔 8px 的瀑布流布局，卡片按内容高度自动排列。打开对应分类时才请求该类列表。

页头只保留主标题和操作按钮，去掉顶部「社区 · 市场」小字与简介，缩小留白，为卡片列表腾出更多高度。搜索、分类切换与标题固定在上方，下方列表拥有独立滚动区域。卡片初次只创建 12 张，接近底部时每批追加 12 张；完整目录元数据用于搜索，因此未显示的条目也能搜到。确认操作后保留当前搜索和浏览位置。每个分类的目录缓存 60 秒，刷新按钮可主动更新。

## 使用

- 插件和技能的顶部搜索框只按卡片标题筛选；人设仍按名称、作者、简介、分类或标识筛选。多个关键词以空格分隔，必须同时匹配。搜索在该分类完整目录中完成，未显示的条目也能搜到。
- 数量右侧可选择「最近更新」或「下载量」。插件、技能默认按更新时间从新到旧，可改为下载量从高到低；同下载量时最近更新优先。切换排序保留搜索词并回到首批卡片，后续滚动继续沿用所选顺序。本次页面内分别记住插件与技能的排序选择。
- 插件和技能卡片展示官网市场的下载量（口令安装下载次数，同设备去重）。官网省略的零计数字段按 0 显示；点击「刷新列表」同步新的计数。人设不显示下载量，也不提供下载量排序。
- 「清空搜索」或在搜索框按 Escape 返回该分类的全部条目。
- 「查看说明」打开条目说明。
- 「安装插件」或「安装技能」先下载并检查 ZIP，显示包内名称、作者、版本和安装确认窗口。
- 点击「安装并启用」后才写入对应目录，等待热重载后调用控制台启用接口；热重载未发现新扩展时才手动重扫，避免重复重载。
- 安装完成可在原有「插件」或「技能」页配置、关闭或删除。
- 两个目录中的同 id 扩展都不会被覆盖，暂不提供升级。

安装包可以有任意多层外部包装目录。插件会定位唯一的 `plugin.json` 或 `skill.json`，核对市场类型、id 和版本，把它及同目录的 `index.js` 和子目录完整安装到 `plugins/<清单 id>/` 或 `skills/<清单 id>/`，保留 `lib`、`assets` 等内部结构。混合多个扩展、类型不符、缺少入口、校验不一致或不安全路径会被拒绝。

## 添加人设

- 人设卡片的「查看人设」按需读取并展示完整人设正文，支持在弹窗内滚动阅读。预览不会新增或选择人设；弹窗中的「添加人设」仍会进入原有确认流程。
- 人设卡片的「添加人设」读取官网完整提示词，弹窗展示「人设名称」和只读的「角色设定」。名称取官网标题，角色设定取原始提示词文本；只去除首尾空白，与宿主新增接口一致。
- 点击「确认添加并使用」后，先调用宿主 `/api/persona-templates` 新增接口，再保存为当前全局人设。确认前取消不会保存。
- 新增时只追加一条自定义人设，即使同名也不会覆盖旧条目。自动选择通过 `/api/config` 提交最小补丁，只更新 `persona.roleText` 与所选模板的 `customRules`（官网人设没有附加规则，置空，与宿主选择人设的行为一致）。
- 新人设在「设置 → 人设」中直接选中，保存成功后才显示完成提示。机器人名字、参与度、分群人设和统一人设开关保持原设置；若统一人设已关闭，已有独立人设的会话仍沿用原配置。
- 新增成功但选择保存失败时，可在弹窗重试；关闭弹窗后卡片显示「选择并保存」，重试不会再次添加同一条目。
- 宿主人设名称最多 50 字；官网标题超过该限制时，弹窗展示完整原名和限制提示，默认前 50 字，可在确认前修改名称。角色设定最大 120000 字。
- 本次会话添加成功的卡片显示「已添加」。关闭或删除市场插件仍保留已添加人设。

## 关闭与卸载

在「插件」页关闭或删除本插件，会撤除它添加的市场页面引用和两个页面文件。只删除 `market-preview` 自己的标记块，不使用整页备份覆盖控制台。原有外部市场入口以及通过市场安装的技能、插件和人设保留。

首次挂载会把控制台入口备份到宿主数据目录下 `market-preview/index-before-market.html`，仅供故障调查。热重载保留引用，避免重复刷新。页面还会检查本插件状态，停用或丢失后自行撤除页签。

0.1.1 修复重复挂载时移动页面引用的问题。已有引用会原位保留，普通插件安装或删除只更新模块列表，不触发市场插件的窗口重载。当前本机的主题接口和扩展管理器也已同步修正重复挂载行为。0.2.0 保留这项修复并加入全部插件、瀑布流及搜索。

## 功能范围

- 后端按分类读取完整目录，筛选已审核且有效的条目，去重后按更新时间排序；人设目录中的提示词正文不会随列表转发，打开添加窗口时才读取所选人设的完整文本。
- 安装包最大 8MB，解压后最大 32MB、100 个文件。不支持带 `node_modules`、运行数据目录、系统脚本或可执行文件的包。
- 依赖能力或必要配置未满足时，仍打开插件开关，但会提示暂未生效原因。
- 不使用模型，不注册机器人工具，不触发 QQ 消息行为。
- 使用 QQ Agent 当前控制台的动作、加载和启用接口及页面容器，客户端或官网接口大幅更新后可能需要适配。

## 文件

`plugin.json`、`index.js`、`lib/plugin-package.js`、`lib/market-client.js`、`host/market-preview-host.js`、`host/market-preview-host.css`。

无需 npm 安装，运行仅依赖宿主与 Node.js 内置模块。
